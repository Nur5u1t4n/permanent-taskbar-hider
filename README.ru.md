# Permanent Taskbar Hider

Мод для Windhawk в Windows 11, который постоянно скрывает панель задач и расширяет рабочую область рабочего стола, чтобы развёрнутые окна доходили до нижнего края монитора.

> **Статус проекта:** личный проект. По сообщению автора, версия 2.0.0 работает на Windows 11 с одним монитором. Независимое тестирование на разных сборках Windows и конфигурациях с несколькими мониторами не проводилось.

## Возможности

- Скрывает основное окно панели задач Windows.
- Перехватывает распространённые вызовы Windows API, которые могут показать, переместить или активировать панель задач.
- Периодически проверяет, что панель остаётся скрытой.
- Расширяет рабочую область основного монитора до его полных границ.
- При отключении мода пытается восстановить сохранённую рабочую область и показать панель задач.
- Логика скрытия панели задач отдельно не скрывает меню «Пуск».

## Совместимость

- Windows 11
- Windhawk
- x86-64
- Конфигурация, проверенная автором: один монитор

Поддержка нескольких мониторов не заявляется. Текущая реализация использует основной монитор и системный API рабочей области.

## Установка

1. Установите [Windhawk](https://windhawk.net/).
2. Откройте в Windhawk пункт **Create New Mod**.
3. Откройте файл [src/permanent-taskbar-hider.wh.cpp](src/permanent-taskbar-hider.wh.cpp), скопируйте его целиком и вставьте в редактор Windhawk.
4. Скомпилируйте и включите мод.
5. В настройках панели задач Windows включите **Автоматически скрывать панель задач** — именно такая конфигурация использовалась при проверке.
6. Отключите другие моды Windhawk, управляющие видимостью панели задач, например **Taskbar auto-hide when maximized**, чтобы избежать конфликтов.

Подробнее: [Инструкция по установке](docs/installation.ru.md).

## Настройки

В версии 2.0.0 нет пользовательских настроек. Поэтому Windhawk может показывать сообщение об отсутствии доступных настроек — это ожидаемое поведение. Подробнее: [Настройки](docs/configuration.ru.md).

## Восстановление и удаление

Отключите мод в Windhawk. Он попытается показать панель задач и восстановить рабочую область, сохранённую при запуске. Если панель не появилась, перезапустите Проводник Windows через Диспетчер задач или перезагрузите компьютер.
