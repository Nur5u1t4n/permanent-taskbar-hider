# Changelog

## 2.0.0

- Hides the primary Windows taskbar window.
- Adds hooks for `ShowWindow`, `SetWindowPos`, and `SetForegroundWindow`.
- Adds a periodic taskbar visibility check (300 ms).
- Expands the primary desktop work area to the monitor bounds.
- Saves the initial work area and attempts to restore it when the mod is disabled.
- Adds Windhawk README metadata and a Russian short description.

This version reflects the working setup reported by the author. It has not been independently compiled or tested as a release artifact in this repository.
