# Установка

## Требования

- Windows 11, x86-64
- [Windhawk](https://windhawk.net/)
- Исходный код проекта: [permanent-taskbar-hider.wh.cpp](../src/permanent-taskbar-hider.wh.cpp)

По сообщению автора, версия 2.0.0 проверялась на Windows 11 с одним монитором. Другие сборки Windows и конфигурации с несколькими мониторами не проверялись.

## Перед включением мода

1. Откройте **Параметры → Персонализация → Панель задач → Поведение панели задач**.
2. Включите **Автоматически скрывать панель задач**. Эта настройка использовалась в проверенной конфигурации.
3. В Windhawk отключите другие моды, которые меняют видимость панели задач, особенно **Taskbar auto-hide when maximized**.

## Установка

1. Откройте Windhawk.
2. Выберите **Create New Mod**.
3. Откройте файл исходного кода по ссылке выше и скопируйте его полностью.
4. Полностью замените содержимое редактора Windhawk скопированным кодом.
5. Нажмите **Compile Mod**.
6. Если компиляция прошла успешно, включите мод.
7. Проверьте, что панель остаётся скрытой при наведении курсора на нижний край, а развёрнутые окна доходят до нижнего края экрана.

## Отключение и восстановление

1. Отключите **Permanent Taskbar Hider** в Windhawk.
2. При завершении мод пытается показать панель задач и восстановить рабочую область, сохранённую при инициализации.
3. Если панель не появилась, перезапустите **Проводник Windows** через Диспетчер задач. Также можно перезагрузить Windows.

## Устранение неполадок

- **Панель задач появляется или мигает:** проверьте, не включён ли другой мод Windhawk, управляющий панелью задач.
- **Развёрнутые окна оставляют пустое место снизу:** убедитесь, что в Windows включено автоматическое скрытие панели задач, затем перезапустите или повторно включите мод.
- **Ошибка компиляции:** сохраните полный вывод компилятора и сравните его с исходником в репозитории. Не смешивайте фрагменты разных версий.

В проект не входят готовый установщик или DLL. Windhawk компилирует исходный код непосредственно на компьютере.
