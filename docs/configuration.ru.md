# Настройки

В версии 2.0.0 нет блока `WindhawkModSettings` и пользовательских параметров.

Windhawk может показывать сообщение **No settings available** («Нет доступных настроек»). Это ожидаемо и не означает, что мод не загрузился.

Поведение задаётся исходным кодом:

- Перехваты управления видимостью панели активны, пока включён мод.
- Фоновый поток проверяет состояние панели каждые 300 миллисекунд.
- Рабочая область расширяется до границ основного монитора.
- Исходная рабочая область сохраняется при инициализации и восстанавливается при отключении.

В настройках Windows должно быть включено автоматическое скрытие панели задач — см. инструкцию по установке. Другие моды, управляющие видимостью панели, следует отключить во избежание конфликтов.

В этой версии намеренно не предусмотрен интерфейс настроек.
